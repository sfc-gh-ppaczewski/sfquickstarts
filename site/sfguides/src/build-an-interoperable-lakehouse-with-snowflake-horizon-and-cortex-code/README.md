# Build an Interoperable Lakehouse with Snowflake Horizon and Cortex Code

This guide walks through building an interoperable lakehouse using Snowflake Horizon and Cortex Code.

## Overview

Learn how to leverage Snowflake Horizon for governance and interoperability alongside Cortex Code for AI-assisted development to build a modern lakehouse architecture.

## Prerequisites

- A Snowflake account
- Access to Snowflake Horizon features
- Cortex Code CLI installed

## What You Will Learn

- How to set up an interoperable lakehouse on Snowflake
- How to use Snowflake Horizon for cross-cloud governance and data sharing
- How to accelerate development with Cortex Code
